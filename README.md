# solo-8800002

一个基于 Vite + Vue 3 的纯前端小众业务示例项目，主题是古籍虫蛀修复批次管理。

## 开发

```bash
npm install
npm run dev
```

`vite.config.js` 已显式配置 `server.open = false`，启动开发服务时不会自动打开浏览器。

## 构建

```bash
npm run build
```

## 工作台导航说明

- 侧边栏提供「修复总览 / 批次档案 / 任务清单」三个入口；窄屏（≤980px）下切换为底部固定导航，入口保持一致可达。
- 三个主视图通过 `KeepAlive` 保留组件状态，路由层用 `src/utils/scrollMemory.js` 记录各入口滚动位置；在入口间快速切换后返回，筛选条件与滚动位置保持不变。
- 未匹配地址进入 404 空态页，可返回总览或跳转任一有效入口，且不会误高亮侧边导航。
- 列表数据为空、筛选无结果、导航入口缺失或数据加载失败时，均展示明确的空态说明与重试入口。
- 在 URL 后追加 `?mockError=1` 可让每类数据的首次加载失败，用于验证失败空态与重试流程；点击重试即可恢复正常数据。
