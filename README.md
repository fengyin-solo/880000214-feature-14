# solo-8800002

一个基于 Vite + Vue 3 的纯前端小众业务示例项目，主题是古籍虫蛀修复批次管理。

## 开发

```bash
npm install
npm run dev
```

`vite.config.js` 已显式配置 `server.open = false`，启动开发服务时不会自动打开浏览器。

## 构建

```bash
npm run build
```

## 工作台导航说明

侧边导航包含 **修复总览**（`/`）、**批次档案**（`/batches`）、**任务清单**（`/tasks`）三个入口，名称与路径保持稳定：

- 三个入口各自通过 `KeepAlive` 缓存，快速连续切换后回到上一入口，筛选条件与页面滚动位置保持不变；窄屏表格的横向滚动位置同样保留。
- 窄屏（≤ 980px）下入口条吸顶，点击汉堡按钮可展开三个入口，点击入口或页面其它区域自动收起。
- 地址不存在时展示明确的 404 空态，可一键回到修复总览，侧边栏不会产生错误高亮。
- 数据为空、加载失败、导航入口缺失/加载失败均有明确空态文案与“重新加载/重试”按钮，不留下白屏。

开发时可通过地址栏 `demo` 查询参数注入异常，验证空态与重试：

| 参数 | 作用 |
| --- | --- |
| `?demo=fail` | 当前页面的数据请求失败（展示失败空态 + 重试） |
| `?demo=empty` | 当前页面的数据返回空（展示空数据空态） |
| `?demo=slow` | 拉长请求耗时，便于验证快速切换时的竞态保护 |
| `?demo=fail-nav` | 侧边导航入口加载失败 |
| `?demo=missing-nav` | 导航中混入一个指向未注册地址的入口（标记“未开通”，就地说明并可重新校验） |

多个参数可用逗号组合，例如 `/tasks?demo=fail,slow`。
